# エントリー管理メモ

アミューズメントポーカー店の営業中に、スタッフがスマートフォン／タブレットのブラウザで使う
簡易メモアプリです。ビルド不要の静的サイト（HTML/CSS/JS のみ）で、データは各端末の
ブラウザ内（localStorage）にのみ保存されます。サーバーや外部システムとの通信は行いません。

## 使い方

1. `index.html` をブラウザで開きます（そのまま開く、または任意の静的サーバーで配信）。
2. 参加者の追加
   - 上部の入力欄に1名ずつ入力して「追加」、または
   - 「複数名をまとめて取込（コピペ）」を開き、`checkInOut` ページ等からコピーした
     参加者名を1行1名で貼り付けて「取込」。既存の参加者と同名の行はスキップされ、
     既存データ（エントリー回数など）は上書きされません。
3. 参加者ごとに「チップ精算」「会計精算」の2種類のエントリーを記録します。
   - **＋**：エントリーを1回追加します（「✓＋回数」のチップが赤色で追加されます）。
   - **✓チップを直接タップ**：タップしたそのチップだけが未反映（赤色）⇄反映済み
     （青色）に切り替わります。周囲の余白をタップしても反応しないため、誤操作を
     防げます。これはポーカータイマー等の外部システムとの自動連携ではなく、
     スタッフがポーカータイマー側へ手入力し終えたことを示すための手動フラグです。
   - **戻**：直前に追加したエントリーを取り消します（入力ミスの訂正用）。
   - 参加者名の右の「×」で、退室した参加者を一覧から削除できます。
4. ヘッダーの「全体リセット」で全参加者のデータを削除できます（確認あり）。営業日の
   切り替え時などにお使いください。
5. 参加者名の横にある3つのステータスボタンで、その場の状況を記録します。
   - **開（シートオープン）**：タップするたびに 白 → 赤 → 青 → 白 … と切り替わります。
     青の状態でチップ精算／会計精算いずれかのエントリーが追加されると、自動的に
     白へ戻ります。
   - **中（プレイ中）**：タップ不可の自動表示です。チップ精算／会計精算のいずれかに
     エントリーが1件でもあれば緑になりますが、シートオープンが白以外（赤・青）の
     間は白のまま表示されます。
   - **待（ウェイティング）**：タップで 白⇄緑 を切り替えます。緑の状態でエントリーが
     追加されると、着席したとみなして自動的に白へ戻り、ウェイティングリストからも
     外れます。
6. 画面左側（狭い画面では上部）の「ウェイティング」パネルに、待（ウェイティング）が
   緑になっている参加者が、緑にした順番に上から表示されます。白に戻ると自動的に
   リストから消えます。

## 表示ルール

エントリー1回につき「✓1」「✓2」…と回数付きのチップが1個ずつ増えます。追加時は
赤色（未反映）で表示され、そのチップ自体をタップすると反映済み（青色）に変わります。
タップ判定はチップの上のみで、チップの周囲の余白をタップしても状態は変わりません。
画面に多くの参加者を並べて表示できるよう、各参加者のカードは横幅の狭いグリッドで
コンパクトに配置されます。

## データについて

- 参加者名・エントリー回数・反映状態は、開いているブラウザの localStorage にのみ保存されます。
- 別の端末やブラウザとはデータを共有しません。ブラウザのデータ消去や別端末での利用時は
  再入力が必要です。
- 参加者名の自動取得（スクレイピング）は行っていません。`checkInOut` ページの内容は
  手動でコピー＆ペーストして取り込んでください。
