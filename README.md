# エントリー管理メモ

アミューズメントポーカー店の営業中に、スタッフがスマートフォン／タブレットのブラウザで使う
簡易メモアプリです。ビルド不要の静的サイト（HTML/CSS/JS のみ）で、データは各端末の
ブラウザ内（localStorage）にのみ保存されます。サーバーや外部システムとの通信は行いません。

## 使い方

1. `index.html` をブラウザで開きます（そのまま開く、または任意の静的サーバーで配信）。
2. 参加者の追加
   - 上部の入力欄に1名ずつ入力して「追加」、または
   - 「複数名をまとめて取込（コピペ）」を開き、`checkInOut` ページ等からコピーした
     参加者名を1行1名で貼り付けて「取込」。既存の参加者と同名の行はスキップされ、
     既存データ（エントリー回数など）は上書きされません。
3. 参加者ごとに「チップ精算」「会計精算」の2種類のエントリーを記録します。
   - **＋**：エントリーを1回追加します（正の字が1画、赤色で追加されます）。
   - **正の字の表示部分をタップ**：一番古い未反映の画を反映済み（青色）に切り替えます。
     これはポーカータイマー等の外部システムとの自動連携ではなく、スタッフが
     ポーカータイマー側へ手入力し終えたことを示すための手動フラグです。
   - **戻す**：直前に追加したエントリーを取り消します（入力ミスの訂正用）。
   - 参加者名の右の「×」で、退室した参加者を一覧から削除できます。
4. ヘッダーの「全体リセット」で全参加者のデータを削除できます（確認あり）。営業日の
   切り替え時などにお使いください。

## 表示ルール

正の字は5画で1文字になる伝統的な集計記号です。エントリーが記録されるたびに1画ずつ
赤色（未反映）で追加され、タップして反映済みにすると同じ画が青色に変わります。
5画たまると1文字分が完成し、6回目のエントリーからは次の文字の1画目として続きます。

## データについて

- 参加者名・エントリー回数・反映状態は、開いているブラウザの localStorage にのみ保存されます。
- 別の端末やブラウザとはデータを共有しません。ブラウザのデータ消去や別端末での利用時は
  再入力が必要です。
- 参加者名の自動取得（スクレイピング）は行っていません。`checkInOut` ページの内容は
  手動でコピー＆ペーストして取り込んでください。
